# Ecos do Ocaso — Documentos oficiais (v0.1)

Este pacote contém a definição inicial de produto e de arquitetura para um RPG Idle 2D de fantasia sombria, em português.

## Documentos

1. `docs/GDD_ECOS_DO_OCASO.md`: o que o jogo será, seus ciclos, conteúdos, sistema de equipamentos, progressão e escopo.
2. `docs/ESPECIFICACAO_TECNICA.md`: como construir o jogo, incluindo módulos, cálculos, salvamentos, testes e roadmap.
3. `GDD_Ecos_do_Ocaso.docx` e `Especificacao_Tecnica_Ecos_do_Ocaso.docx`: versões para leitura e revisão em editor de documentos.

## Uso sugerido no Cursor

- Copie a pasta `docs/` para a raiz do repositório.
- Inicie o projeto com o template oficial Phaser + React + TypeScript + Vite.
- Peça ao Cursor para ler integralmente os dois documentos e trabalhar **somente nas Etapas 0 e 1** da especificação técnica.
- Mantenha as regras e valores numéricos sincronizados entre o código, os dados do jogo e a documentação.
- Revise as decisões pendentes após a demonstração da primeira arena funcional.

**Importante:** o nome *Ecos do Ocaso* e os números de balanceamento são propostas iniciais, não decisões irrevogáveis.
